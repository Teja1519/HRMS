Human Resource Management System (HRMS)
Overview

Human Resource Management System (HRMS) is a web-based application developed as a B.Tech academic team project using the MERN stack. The system automates and simplifies various HR processes, improving efficiency in employee management and organizational operations.

Features

* Employee Management
* Attendance Tracking
* Leave Management
* Payroll Management
* Role-Based Access Control
* Employee Records Management
* Dashboard and Reporting

Tech Stack

* Frontend: React.js
* Backend: Node.js, Express.js
* Database: MongoDB
* Version Control: Git & GitHub

Project Type:
Academic Team Project (B.Tech)

Objective:
      To automate routine HR tasks, reduce manual effort, improve record management, and provide a centralized platform for HR operations.
